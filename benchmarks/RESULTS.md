# FuseDB comparative benchmark

The previous legacy results were removed because they used an internal
API, mixed durability contracts, and combined measurements from different
engine generations.

Current results are generated by [`kvbench`](./README.md) from the public
FuseDB API and equivalent Pebble, Badger, and RocksDB point operations. A fresh
versioned JSON report and its Markdown rendering will be recorded from a clean
Git commit.
